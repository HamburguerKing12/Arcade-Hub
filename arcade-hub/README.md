# Arcade Hub

A static browser-game website built with HTML, CSS, and JavaScript.

## Run it locally
Open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new **public** repository named `arcade-hub`.
2. On the repository page, choose **Add file → Upload files**.
3. Upload `index.html` from this folder and commit the changes.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then click **Save**.
7. Wait for the Pages deployment. Your site URL will look like:
   `https://YOUR-USERNAME.github.io/arcade-hub/`

GitHub Pages may take a few minutes to publish the first time.

## Games
Eight small games are built into the page. Four additional cards open the games on their respective external sites:
- ! PANIC ! — poppants on itch.io
- Pixel Speedrun — browser remake hosted at pixelspeedrun.com (not affiliated with the original developer)
- OvO — CrazyGames
- Eaglercraft — Eaglercraft's play page

External games are not copied into this repository; their availability, terms, and compatibility are controlled by their respective sites. Use games where permitted and follow the rules of the network you're using. This site does not bypass network restrictions.
